# Build Guide — AmneziaWG Windows Client

## Overview

This is the build documentation for the AmneziaWG Windows client with **split-tunneling** support.
The project is a Go-based Windows GUI application built on top of the [lxn/walk](https://github.com/lxn/walk) toolkit.

## Prerequisites

- **Go 1.22+** — with CGO enabled (gcc/MinGW required)
- **rsrc** — Go resource compiler (`go install github.com/akavel/rsrc@latest`)
- **ImageMagick** (portable) — for SVG→ICO conversion
- **Git**

## Build Process

### 1. Generate Icons from SVG

```powershell
# Download ImageMagick portable
$url = "https://download.wireguard.com/windows-toolchain/distfiles/ImageMagick-7.0.8-42-portable-Q16-x64.zip"
Invoke-WebRequest -Uri $url -OutFile "$env:TEMP\imagemagick.zip"
Expand-Archive "$env:TEMP\imagemagick.zip" -DestinationPath "$env:TEMP\imagemagick" -Force

# Find convert.exe and render ICOs
$convert = Get-ChildItem "$env:TEMP\imagemagick" -Recurse -Name "convert.exe" | Select-Object -First 1
& "$env:TEMP\imagemagick\$convert" -background none "ui\icon\wireguard.svg" `
    -define icon:auto-resize="256,192,128,96,64,48,40,32,24,20,16" `
    -compress zip "ui\icon\wireguard.ico"
& "$env:TEMP\imagemagick\$convert" -background none "ui\icon\dot.svg" `
    -define icon:auto-resize="256,192,128,96,64,48,40,32,24,20,16" `
    -compress zip "ui\icon\dot.ico"
```

### 2. Generate Resources (.syso)

```powershell
rsrc -manifest manifest.xml -ico ui/icon/wireguard.ico,ui/icon/dot.ico -o rsrc.syso
```

This embeds the Windows manifest (Common Controls v6, DPI awareness) and application icons.

### 3. Run `go mod vendor`

```powershell
go mod vendor
```

### 4. Apply Vendor Patch (icon resource ID)

> **Why:** The original project uses `windres` from llvm-mingw which assigns icon resource IDs
> as specified in `resources.rc` (ID 7 for wireguard.ico, ID 8 for dot.ico).
> The `rsrc` tool assigns sequential IDs starting from 1:
> | Resource | rsrc ID | windres ID |
> |----------|---------|------------|
> | Manifest | 1 | 1 |
> | wireguard group icon | 2 | 7 |
> | dot group icon | 14 | 8 |
>
> The source files `ui/iconprovider.go` already use the rsrc IDs (2 and 14).
> But the vendored `lxn/walk` library hardcodes `MAKEINTRESOURCE(7)` for the
> window class icon in `window.go:488`. Apply this patch:

```powershell
# Fix walk window.go to use rsrc icon ID 2 instead of 7
(Get-Content vendor\github.com\lxn\walk\window.go) -replace `
    'win.LoadIcon\(hInst, win.MAKEINTRESOURCE\(7\)\) // rsrc uses 7 for app icon',
    'win.LoadIcon(hInst, win.MAKEINTRESOURCE(2)) // rsrc uses 2 for app icon (first ICO after manifest)' `
    | Set-Content vendor\github.com\lxn\walk\window.go
```

### 5. Build

```powershell
$env:CGO_ENABLED = "1"
$env:GOOS = "windows"
$env:CC = "gcc"

go build -mod=vendor -ldflags="-H windowsgui -s -w" -trimpath -o amneziawg.exe .
```

**Critical build flags:**
- `-H windowsgui` — suppresses console window (required for GUI app)
- `CGO_ENABLED=1` — **required** for proper .syso resource linking
- `-mod=vendor` — uses vendored dependencies

## Why CGO Is Required

Go's internal linker (`CGO_ENABLED=0`) does not correctly process the COFF `.syso` file
generated by `rsrc`. Specifically:

1. The `.rsrc` section in the final PE is truncated (~1.5 KB instead of ~780 KB)
2. Icons are missing from the binary
3. The manifest may not be loaded as an activation context

**With CGO**, the GCC linker properly merges the `.syso` resources, producing a valid PE
with all icons and manifest embedded.

## Common Issues

### "ITM ADDTOOL failed" crash

```
Stack: walk.newError("TTM_ADDTOOL failed") → ToolTip.addTool() → WidgetBase.init()
```

**Root cause:** Without a properly embedded Windows manifest, Common Controls v6 is not
activated. The ToolTip control (`tooltips_class32`) requires v6. This happens when:
- CGO is disabled → `.syso` not linked correctly
- `.syso` file missing or empty

**Fix:** Build with `CGO_ENABLED=1` and a valid `rsrc.syso`.

### No tray icon visible

**Root cause:** Icons not embedded in the binary. Without `windres`, the `.ico` files
must be converted from SVG and embedded via `rsrc`.

**Fix:** Generate ICOs with ImageMagick, run `rsrc`, build with CGO.

### Console window appears instead of GUI

**Root cause:** Missing `-H windowsgui` linker flag.

**Fix:** Add `-ldflags="-H windowsgui"` to the build command.

## CI/CD Build

The original `build.bat` script handles the full pipeline (download deps, render icons,
compile for amd64/x86/arm64). However, it requires llvm-mingw `windres` which we replace
with the pure-Go `rsrc` tool.

For automated builds, ensure:
1. `rsrc` is installed (`go install github.com/akavel/rsrc@latest`)
2. ImageMagick is available for SVG→ICO conversion
3. CGO is enabled with a working GCC toolchain
